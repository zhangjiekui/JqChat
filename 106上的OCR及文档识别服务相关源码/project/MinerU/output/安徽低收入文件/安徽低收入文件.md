# 、工作要求  

市级民政部门要以建设低收入人口动态监测信息平台为依托，优化本级社会救助信息系统，横向整合专项救助及乡村振兴局、残联等部门信息，对接财政惠农补贴资金“一卡通”系统，纵向与在建的安徽省民政厅社会救助大数据信息系统对接，实现低收入人口等社会救助对象的信息汇聚、常态监测、快速预警，做到即时干预、精准救助、综合帮扶，切实保障好困难群众基本生活，以实际行动为基层减负，确保民政系统巩固拓展脱贫攻坚成果同乡村振兴有效衔接工作落到实处。
