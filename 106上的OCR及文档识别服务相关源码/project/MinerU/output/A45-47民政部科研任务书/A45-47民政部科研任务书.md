# 研究背景  

本课题研 究的基本思  
路、  
技术路  
线、  
研究框架和研究方法  

医疗救助能够保障贫困人群健康权益，体现社会公平，稳定社会发展，是我国社会救助体系的一个重要组成部分。2014年全国实施医疗救助9119万人次，支出医疗在对象认定不够精准、资金使用不够规范，缺乏有效监督、资金支出信息不够透明等问题。  

为了保证我国社会救助体系的健康安全发展，《社会救助暂行办法》（2014年国务院令第649号）明确规定社会救助审核认定过程中需要进行家庭经济状况信息核对。民政部为推进居民家庭经济状况核对做了大量卓有成效的工作，截止2015年5月，我国已有11个省份信息核对系统已建成使用或正在建设，2015年1-5月，全国共开展各类业务受托核对3687万次，其中开展最低生活保障受托核对3337万次，开展住房保障受托核对290万次，但目前医疗救助核对工作还处于摸索、起步阶段，虽有部分省市出台了相关的政策文件，但还缺乏具体、规范的操作流程。  

本课题将从分析目前医疗救核对工作开展情况和存在问题入手，通过实地调研，以现有政策为基础，研究如何规范和优化医疗救助对象的家庭经济状况核对工作流程。  

# 二、研究目标  

以现有政策为基础，实地调研各地开展医疗救助核对工作的条件和困难，梳理分析医疗救助对象审核认定流程及存在问题，制定和优化医疗救助核对业务流程。  

# 三、研究内容  

1、医疗救助对象分类  

医疗救助对象既包括低保、五保等已经认定过的民政救助对象，也包括低收入、因病致贫的边缘待认定人群，还有县级以上人民政府规定的其他特殊困难人员，部分临时救助对象。  

本课题将首先对医疗救助的对象进行调研和归纳分类，明确具体的申请条件，分类评估各类医疗救助对象开展核对工作的必要性可行性，整理出需要进行居民家庭经  

济状况核对的对象类别和核对项目。  

2、制定和优化医疗救助核对业务流程  

在医疗救助对象审核认定中，针对不同类型的申请对象，研究制定与之相对应的业务流程。本课题将通过实地调查各类医疗救助对象审核认定流程及存在问题，收集和整理相关的思路、建议，在充分研究理解医疗救助政策、对象类型、审核认定流程的基础上，分类制定、优化相应的业务流程和相关业务模板、样例，包括医疗救助核对受理流程、审批流程、跨机构协作流程、内部工作流程、流程节点、流程节点衔接、节点时限要求、输入输出、机构、角色，业务用例等，并根据业务流程、核对要求，整理形成业务模板和样例，为各地提供参考。  

3、形成医疗救助系统与居民家庭经济状况核对系统的集成标准  

在明晰和定义医疗救助业务流程的基础上，参照结合《居民家庭经济状况核对标准》，并视需要拓展，从医疗救助核对项目委托、受理、审批、核对、数据交换、流程衔接、标准接口等方面，形成医疗救助系统与居民家庭经济状况核对系统的集成标准，保证信息系统集成的顺利进行。  

# 四、研究框架和研究方法  

业务层面上，充分调研，在对医疗救助对象进行分类，并理解医疗救助审核认定流程的基础上，明确医疗救助核对的作用重点，分类梳理、制定优化相应的业务流程和相关业务模板、样例。  

信息标准层面上，基于已定义的业务流程、模板和样例，参照结合《居民家庭经济状况核对标准》，从医疗救助核对项目委托、数据交换、流程衔接、标准接口等方面，形成医疗救助系统与居民家庭经济状况核对系统的集成标准。
