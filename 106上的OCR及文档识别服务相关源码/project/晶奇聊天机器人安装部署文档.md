## 2. 开发环境准备

### 2.1 Windows环境配置

#### 2.1.1 Python版本选择
🔹 推荐使用 Python 3.13.x 版本
- 下载地址：https://www.python.org/downloads/
- 安装注意事项：
  * 选择 64 位安装包
  * 自定义安装
  * 勾选 "Add Python to PATH"
  * Install,等待进度条完成
  

#### 2.1.2 虚拟环境创建

##### Python venv创建(可选)
```powershell
# 创建虚拟环境

# 激活虚拟环境
.\jinqichat_env\Scripts\activate
```

##### pip配置

### 2.2 Ubuntu环境配置

#### 2.2.1 系统更新与Python安装
```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装Python
# 从官网下载源文件
wget https://www.python.org/ftp/python/3.10.0/Python-3.10.0.tgz

# 解压缩Python3.10文件
find / -name Python-3.10.0.tgz
cd /home/
cp /root/Python-3.10.0.tgz /home/
tar -zvxf Python-3.10.0.tgz 

# 开始安装
cd Python-3.10.0/
./configure --enable-optimizations

# 编译
make && make install
```

#### 2.2.4 MinerU安装
- 安装MinerU依赖
```bash

pip install -U magic-pdf[full] --extra-index-url https://wheels.myhloli.com -i https://mirrors.aliyun.com/pypi/simple

```

下载完成后，务必通过以下命令确认magic-pdf的版本是否正确
```bash
magic-pdf --version
```
版本号不小于0.7.0

- 下载模型

使用python脚本 从ModelScope下载模型文件
```bash
pip install modelscope
wget https://gitee.com/myhloli/MinerU/raw/master/scripts/download_models.py -O download_models.py
python download_models.py
```

- 了解配置文件存放的位置
完成下载模型步骤后，脚本会自动生成用户目录下的magic-pdf.json文件，并自动配置默认模型路径。 您可在【用户目录】下找到magic-pdf.json文件。

```

{
    // other config
    "layout-config": {
        "model": "layoutlmv3" // 使用doclayout_yolo请修改为“doclayout_yolo"
    },
    "formula-config": {
        "mfd_model": "yolo_v8_mfd",
        "mfr_model": "unimernet_small",
        "enable": true  // 公式识别功能默认是开启的，如果需要关闭请修改此处的值为"false"
    },
    "table-config": {
        "model": "rapid_table",  // 默认使用"rapid_table",可以切换为"tablemaster"和"struct_eqtable"
        "enable": false, // 表格识别功能默认是关闭的，如果需要开启请修改此处的值为"true"
        "max_time": 400
    }
}
```

如json内没有如下项目，请手动添加需要的项目，并删除注释内容（标准json不支持注释）

- 测试运行

从仓库中下载样本文件，并测试
```bash
wget https://gitee.com/myhloli/MinerU/raw/master/demo/small_ocr.pdf
magic-pdf -p small_ocr.pdf -o ./output
```

- 测试CUDA加速

修改【用户目录】中配置文件magic-pdf.json中"device-mode"的值
```bash
{
  "device-mode":"cuda"
}
```

或者：
```bash
magic-pdf -p small_ocr.pdf -o ./output
```

## 4. 服务部署
### 4.1 Windows服务部署

### 4.2 Ubuntu服务部署
- 服务器名称:10.1.150.106
- OCR服务
```bash
# 启动步骤：
source /usr/local/bin/virtualenvwrapper.sh
workon ocrbase
cd ~ [否则会提示找不到文件]
CUDA_VISIBLE_DEVICES=1 nohup  python /root/project/practice/api.py >> /root/project/practice/logs/ocr_run_20241121_5566.log &
```
tail -f /root/project/practice/logs/ocr_run_20241121_5566.log

- MinerU服务

```bash
# 启动步骤：
source /usr/local/bin/virtualenvwrapper.sh
workon MinerU
cd /root/project/MinerU/
nohup python /root/project/MinerU/projects/web_api/app.py >> /root/project/MinerU/projects/logs/mineru_run_20240022_8888.log &
```

- 停止服务

```bash
## 找到程序的pid
ps -ef | grep api.py
## 假设找到的pid为9999
kill -9 9999


## 查看端口是否被占用
netstat -anp |grep 端口号


```

最后一列显示被某服务占用及对应得PID,kill -9 PID即可关闭进程，重新启动服务
